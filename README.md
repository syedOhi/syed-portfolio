# Syed — portefólio

Portefólio em português de Portugal, com apresentação, serviços, email, WhatsApp e uma demonstração independente para a Tasca O Bernardo.

HTML, CSS e JavaScript, sem instalação de dependências nem etapa de compilação. No repositório publicado, `index.html` está na raiz. Para pré-visualizar: `python -m http.server 8766 --bind 127.0.0.1`. Na cópia de trabalho original, os ficheiros públicos encontram-se na pasta `dist`.

Os contactos foram fornecidos por Syed para divulgação pública. As ligações de email e WhatsApp abrem a aplicação do visitante; o website não recolhe nem envia mensagens automaticamente.

A demonstração está em `work/tasca/`, tem sete idiomas e não aceita reservas reais. É um conceito independente, não encomendado pelo restaurante. As fotografias e a marca provêm do projeto original; as permissões de reutilização não foram verificadas.

Configuração Netlify: ramo `main`, sem comando de compilação, diretório de publicação `.`.
